# OMOS Integration Status — 2026-09-15

## Repository role

`ohi-stack/onegodian-protocol` remains the specification source for the OneGodian Protocol™, OneGodian Algorithm™, and related public-safe identity/alignment definitions.

The canonical OMOS runtime/site implementation is `ohi-stack/omos-site/main` at the production target `https://omos.onegodian.com`.

## Integration contract

- Protocol = definitions, identity rules, semantics, scope, interoperability, transparency, and human-authority boundaries.
- OneGodian Algorithm = Observe → Distill → Align → Select → Execute → Verify.
- O-H-I = multi-model comparison, critique, dissent preservation, evidence-gap detection, and governed synthesis.
- OMOS = runtime, orchestration, provider routing, interfaces, Human Gate, persistence, audit, and Decision Records.

OMOS may implement or render Protocol/Algorithm material, but runtime behavior does not redefine the specification by implication. Specification changes should be versioned here and then deliberately upstreamed into OMOS implementation/docs.

## Current runtime target

The canonical OMOS repository targets runtime `1.1.0` with normalized OpenAI/Anthropic/Gemini/xAI Model Gateway contracts, PostgreSQL Decision Record durability, owner isolation, audit chaining, strict production preflight, MCP authorization hardening, and OMOS-REF-0001 verification tooling.

## Production boundary

As of September 15, the canonical public host was still observed on runtime `1.0.1`; repository implementation is therefore ahead of production deployment. Protocol specification status must not be conflated with deployed-runtime status.
